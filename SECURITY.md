# Security Policy

This repository is a static portfolio site, but reports are still welcome: anything that could expose
secrets, compromise the CI/CD pipeline, or let someone inject content into the deployed site.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/pyand3v/devfolio/security/advisories/new)
with steps to reproduce and the impact you expect. You'll get a reply as soon as possible, and credit in
the fix if you'd like it.

## Supported versions

Only the latest deployment from `main` is supported.
