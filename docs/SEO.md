# SEO guide

Astro renders all public pages statically and supplies the site-wide SEO configuration from `src/data/site.ts`.

## Included SEO assets

- Canonical URLs, title/description, Open Graph, Twitter, and robots meta tags in `src/layouts/BaseLayout.astro`
- JSON-LD for the home page, blog posts, work items, and projects. The home page (every locale) and blog posts are built by `src/lib/structured-data.ts`: a `Person` (`/#person`, with the footer's profiles as `sameAs`) and the `WebSite` they publish, and a `BlogPosting` per post with its dates, language (`inLanguage`), tags, reading time, and the same `Person` as author and publisher
- Build-time PNG Open Graph images for every home, list, tag, and detail route
- `robots.txt`, `rss.xml`, and `llms.txt` endpoints in `src/pages/`
- One RSS feed per locale: `/rss.xml` (English) plus `/es/rss.xml` and `/pt-br/rss.xml` with the posts translated into that language, built by `src/lib/rss.ts`. Every page links its locale's feed with `<link rel="alternate" type="application/rss+xml">` (no `hreflang`: Lighthouse reads any `rel="alternate" hreflang` link as a page alternate and fails it for a relative URL)
- `sitemap.xml`, generated by the `src/pages/sitemap.xml.ts` endpoint (English routes: home, list pages, blog posts and tags, work items, and projects)
- Translations: every translated page is its own canonical URL (`/es/blog/x`) and lists its language versions with `<link rel="alternate" hreflang>` plus `x-default` (English), from `BaseLayout`'s `translations` prop (default: every locale). Pages that aren't translated pass `translations={[]}`: English-only work and project pages, tag pages (tag names differ per locale), and a blog post shown in English for lack of a translation, whose canonical is the English post. Open Graph images are rendered for the unprefixed routes and shared by translations, except translated blog posts, which get their own in their language
- The inline locale redirect never moves a visitor without a stored language away from an explicitly localized URL, so crawlers (which browse in English with no storage) can index translations. `pnpm links:check` also verifies every page's canonical, `og:image` and hreflang URLs exist

Set `PUBLIC_SITE_URL` in the deployment environment to your final canonical origin. Update `src/data/site.ts`, `src/data/portfolio.ts`, and the MDX frontmatter before publishing.
